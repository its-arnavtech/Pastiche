# 0004 cursor-opus: owned paths, packaging before T-001, event envelope

- Context: `cursor-opus` starts T-014..T-016 before T-001 (pyproject, `src/remixer/__init__.py`, interfaces) exists on `dev`. The seeded task files list owned paths (`src/remixer/events/`, `src/remixer/player/`, FastAPI player) that differ from the paths in the `cursor-opus` brief (`src/remixer/analytics/`, `src/remixer/fatigue/`, `web/`, `tests/analytics/`, `tests/fatigue/`, `tests/web/`, later `tests/contracts/`).
- Decision:
  - The brief's paths win. Event schema, interpretation, heatmap and simulator live in `src/remixer/analytics/`; fatigue, credit, attribution and selection in `src/remixer/fatigue/`; the static player plus a stdlib mock backend in `web/`. The `owns_paths` of T-014..T-016 are updated to match.
  - `src/remixer/` gets no `__init__.py` from this branch: `remixer` stays an implicit namespace package, so `remixer.analytics` imports today and keeps working when T-001 adds `remixer/__init__.py` with `PROJECT_NAME`. The web UI reads the project name from the backend (`remixer.PROJECT_NAME` when it exists), so the name stays in one constant.
  - A bare `pyproject.toml` (no build backend, no entry points) is created with `uv init --bare` only to carry optional groups `analytics` (numpy, duckdb, pyarrow), `web-test` (playwright), the `dev` group (pytest, hypothesis) and pytest settings. `opus-cc` merges this into the T-001 pyproject; on conflict keep T-001's file and re-add these groups.
  - Core interpretation, heatmap, simulator, fatigue and selection are stdlib-only; numpy (attribution), duckdb/pyarrow (scale path) and playwright (UI tests) are optional and their tests skip when missing.
  - One event envelope for every control: the T-014 fields plus an optional `payload` object. Playback types are the seven in spec section 5; rating (`rate_up`, `rate_down`, `rate_tired`, `rate_clear`) and insight-answer (`insight_yes`, `insight_no`, `insight_unsure`) types use the same envelope so the UI has one sink. Interpretation ignores non-playback types.
  - `CHANGELOG.md` is not regenerated on this branch (generated file, regenerate on merge).
- Alternatives: creating `remixer/__init__.py` and a full pyproject here (guaranteed add/add conflicts with T-001); separate event schemas per control family (two sinks, two validators).
- Consequences: `uv run pytest` runs the stdlib-only tests; `uv run --all-extras pytest` runs everything. When T-001 lands, the `EventSink` adapter stores this envelope unchanged.
